# 07 — UI/UX

## Principes

1. **Ne jamais couvrir** la main, les intents ennemis, ni les boutons de fin de tour.
2. **Une seule surface** : un panneau vertical fin, ancré à droite (zone morte de l'écran
   en 16:9 et 21:9), largeur ~260 px.
3. **Opacité au repos 0.3**, 1.0 au survol, transition 150 ms.
4. **Hotkeys** : `F8` toggle global, `F9` mode détaillé, `[`/`]` re-dimensionner.
5. **Zéro animation** qui attire l'œil en combat (pas de pulse permanent).
6. **Lisibilité** : police du jeu (`MegaLabel`/thème existant), taille min 14 px.

## Layout (mode compact)

```
┌─ ULTIMA ────────────────┐
│ T3 · 62/80 PV · 12 block│   ← statut joueur

│ ⚔ Jaw Worm             │

│   Weak 12x3 → 2e létal  │   ← variante (gris)
│─────────────────────────│
│ ⚔ Cultist               │
│   6x2 → bloqué (blk 14) │
│─────────────────────────│
│ PRIO: Backflip (P2)     │   ← F3
│─────────────────────────│
│ DECK 7.4 · Draw 12      │   ← F4 (score)
└─────────────────────────┘
```

Mode détaillé (`F9`) : table des contributions (carte, dégâts run/combat, % joué),
export CSV.

## Ancrage des badges d'intent

Deux options, à trancher à l'implémentation :
- **A. Badge séparé** ancré à droite de l'intent natif (offset calculé depuis la position
  du node `NIntent`). Plus propre visuellement, dépend du layout du jeu.
- **B. Ligne dans le panneau ULTIMA** (recommandé V1) : zéro risque de casser sur patch.
  On passe à A en V2 si le rendu est validé.

## Accessibilité

- Contraste ≥ 4.5:1 sur le texte.
- Le létal est signalé par **texte + couleur** (pas seulement rouge).
- Toutes les valeurs numériques alignées à droite (comparaison rapide).

## Pièges Godot déjà identifiés (vérifiés dans 999dulgi)

- `MouseFilter = Ignore` sur le root, puis réautoriser explicitement les enfants
  interactifs (`Stop`) — sinon les boutons ne répondent plus.
- Scroll : `_UnhandledInput` + wheel manuel quand le filter est Ignore.
- `ScrollContainer` : cacher la scrollbar via `GetVScrollBar().Modulate = Colors.Transparent`
  en `CallDeferred` (le `ShowNever` ne suffit pas toujours).
- `SizeFlagsVertical = ExpandFill` sur les parents du ScrollContainer.
- Cleanup dans `_ExitTree` (plus fiable que `_Notification`).
